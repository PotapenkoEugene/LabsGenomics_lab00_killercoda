# Lab 08 Homework (Part 1) — Alternate Environment

The course server is unreachable — this VM is a drop-in replacement.

This is **Part 1 of 2**. Here you download, QC, trim, and assemble the genome. Part 2
(annotation + resistance screening) is a separate scenario — do this one first.

The 4 tools this part needs — `fastqc`, `fastp`, `seqkit`, `megahit` — are installed and
activated automatically on login, ready to run directly. You never need to type
`conda activate` or `conda create` — it's already done.

> **After you press Start, wait for the prompt to change** from root@ubuntu to (tools)
> student@ubuntu before typing anything — this can take **1–2 minutes**. Just wait.
> Killercoda can be laggy — if it's still root@ubuntu after 5+ minutes and nothing is
> happening, **reload the page and restart the scenario**.

Follow the **Lab 08 homework PDF on Moodle** for full task instructions. This scenario only
gives you a place to run them and a way to get `answers_1.txt` back out.
